# سير العمل

`masari-workflow.json` هو سير عمل n8n جاهز للاستيراد: من **⋯** اختر **Import from File**.

- الملف لا يحتوي أي توكن أو مفتاح. اربط حساب تليجرام وحساب Gemini بعد الاستيراد.
- بعد الاستيراد افتح عقدة **Google Gemini Chat Model** واختر من القائمة نموذج Flash مستقراً متاحاً لحسابك، فأسماء نماذج Gemini تتغير مع الوقت.
- خطوات التشغيل الكاملة في [`guides/setup-guide.md`](../guides/setup-guide.md).
